保证不重叠的布局规则

  1. 固定节点盒模型：所有节点先统一测量为固定宽高，例如 220 × 96。节点内容超出则截断，完整内容进入右侧 Inspector。
  2. 拓扑分层：根据 PROV 边计算 layer，上游 layer 小，下游 layer 大。每个 layer 是一行。
  3. 同层排布：同一 layer 的节点横向排列，间距 = nodeWidth + columnGap。行高 = nodeHeight + rowGap。
  4. 画布自增长：画布宽高由最大 layer 节点数和 layer 数计算，不强行塞进视口；允许滚动和缩放。
  5. 边按层绘制：边从节点底部到下游节点顶部，边 label 放在中点，必要时使用曲线避让。

节点内容边界

节点内只保留：名称 + 一句简短描述。不放完整路径、input/output 列表、完整参数、代码片段、raw PROV。这些全部放右侧 Inspector。
