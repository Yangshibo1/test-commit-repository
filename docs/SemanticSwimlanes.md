# 四泳道语义聚合工作流

用于顶部第三个入口「工作流可视化」。第四个入口的逐 Event、Turn 并列图保持独立。

## 四列与聚合语义

从左到右固定为输入、规划、执行、修改。每列包含多个语义块，不能把整次会话压成四个大节点。

| 泳道 | 范围 |
| --- | --- |
| 输入 | 任务、约束、资源接收、数据理解与探索 |
| 规划 | 已明确记录的任务拆解、方法/指标/路径选择、方案确认 |
| 执行 | 沿当前方案读取、清洗、计算、分析、绘图、验证、综合和成果交付 |
| 修改 | 基于异常、新发现、验证或用户反馈，对既有方案、代码、范围、流程或结论进行纠偏 |

首次写代码、常规文件编辑或验证通过不自动进入修改；修改后重新运行通常回到执行。
规划必须有已记录的选择或安排，不能恢复 hidden chain-of-thought。某列没有对应行为时保持空列，不为视觉均衡补造阶段。

新增层消费已有 `semantic_nodes` 的标题、目标、摘要、结果、异常、置信度、Turn 归属及原阶段关系。
不重新切分或提取 Transcript。模型用当前语义 API 配置（gpt-6.1-sol、medium），通常一次全局请求；结构问题最多一次修复。
只合并同一 Turn 内、在全局阶段序列连续、同一泳道且共同服务一个明确子目标的块。
不能仅因活动类型或泳道相同而合并。非 NEXT 语义关系的两个端点不得进入同一块，保留验证、修订、重试及结果引用的区别。

每个原阶段恰好归属一个聚合块，不拆分、不遗漏。信息不足时保留单阶段块并说明限制。
输出 title、summary、reason、confidence、lane、node_ids；代码添加稳定 group_id、原 event_ids 和 inferred 来源。
聚合解释不继承原阶段的人工确认状态。摘要可保留关键数字与限制，但不能将报告或计划转为已核实执行。
后台验证覆盖、顺序、Turn 边界、关系端点及枚举，不能证明模型的分类和摘要一定正确。

## 布局与回溯

横向推进可共享一行，重访同一列或较早的列时向下推进。因此输入 → 规划 → 执行 → 修改可同排，修改 → 执行进入下一行。
列内从上到下与原顺序一致；卡片编号对应原阶段序号或范围。展开聚合块时，恢复原阶段卡片和精确关系端点。

灰色虚线表示原 NEXT 记录顺序。彩色实线是原阶段语义关系，不是此聚合模型新增的关系。
VALIDATES、REFINES、RETRY_OF、USES_RESULT_FROM 继续保留原引用方向，可能指向较早阶段；不能将它们冒充顺向因果依赖。
跨块同端点同类型的多条关系合并绘制，保留全部原 relation_id 与 evidence_event_ids；块内 NEXT 在展开时恢复。
连线采用正交避障，减少穿过卡片和重复走线。泳道只是组织语义，不构成额外关系。

点击语义块打开紧凑详情浮层，单一头部下用“聚合概览 / 原阶段”切换正文，共用一个滚动区。概览优先展示行为摘要、结果与关键动作；长摘要可展开，依据与证据默认折叠。原阶段不超过三个时用单行按钮切换，更多时使用下拉框，保留阶段目标、结果、异常及原始证据回溯。文件作为块内快捷入口，不占第五列。
平移、缩放、全图查看及原始 Transcript 证据跳转继续可用。详情与目录默认关闭，并以浮层打开，以保留四列画布空间。

## 文件、缓存与接口

- `derived/semantic_swimlanes.json`：当前聚合版本（semantic-swimlanes/0.1）。
- `derived/semantic_swimlanes/`：覆盖前归档旧聚合版本。
- `derived/semantic_swimlane_stages/<fingerprint>/`：请求、原模型输出、修复输出、校验后输出及状态。
- `/api/observations/{sid}/semantic/swimlanes`：读结果。
- `/api/observations/{sid}/semantic/swimlanes/generate`：异步生成。
- `/api/observations/{sid}/semantic/swimlanes/progress`：进度与错误。

指纹包含已有工作流全部内容、聚合版本、模型与思考强度。原阶段生成或人工复核变化后旧聚合失效；运行期间来源变化则不覆盖现有结果。
超出全量输入预算时明确停止，不删阶段。失败保留检查点及原工作流；读取页面不会自动向 API 发送记录。
尚未聚合时，前端按已有 primary_activity 和明确规划标题保守归类为单阶段块，并标明“按现有阶段归类”。点击“聚合语义”后应用 AI 聚合结果。

测试覆盖完整归属、跨任务禁止合并、语义端点保护、缓存与来源失效、失败重试、异步接口、同排布局、修改后回访执行、展开原阶段和卡片避障。
