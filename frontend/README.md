# AgentVAST Frontend

基于 React + React Flow + Dagre 的 AgentVAST 数据血缘可视化前端。

## 技术栈

- **Vite** - 快速构建工具
- **React 18** - UI框架
- **TypeScript** - 类型安全
- **React Flow** - DAG交互组件
- **Dagre** - 自动布局算法
- **Tailwind CSS** - 样式
- **ECharts** - 图表可视化

## 安装

```bash
cd frontend
npm install
```

## 开发

```bash
npm run dev
```

访问 http://localhost:3000

## 构建

```bash
npm run build
```

## 功能

工作台统一使用四项主导航：

- **Claude 运行**：终端铺满导航下方的可用空间；启动设置作为可收起的浮层，运行时默认收起。切换页面时保留终端组件和会话状态，并在页面显示或窗口变化后自动调整终端行列。
- **原始 Transcript**：标题、统计和会话选择合并为紧凑栏，以全宽区域展示记录。提供“调用链视图 / 原始日志 / 工具详情”和“复制日志”；调用链无搜索栏，按证据行定位。原始日志直接显示完整 JSONL，可切换格式化与原文、加载本地文件；调用链和工具详情在需要时分页。
- **工作流可视化**：展示语义阶段、产物和证据；点击证据会跳转到原始 Transcript 的对应行。
- **Agent 详细执行工作流**：以六类 Event 为节点。基础执行图无需模型；点击“生成 AI 工作流”可生成逐事件摘要、逻辑关系和核心/支撑/背景评估，支持恢复和导入结果。绿色为逻辑推断，灰色为规则补充，虚线表示待核查或记录顺序。“突出关键事件”调整三档卡片大小，保留全部 Event。详情展示重要性理由、推断解释、输入输出和原始证据。

- 加载 AgentVAST session 文件夹
- 显示 PROV DAG（使用 Dagre 自动布局）
- Timeline 展示分析步骤
- Inspector 查看节点详情
- Follow-up 生成 Claude 继续问答命令
- ECharts 数据集可视化
- 调用链按记录顺序展示初始化、用户消息、模型响应和工具操作；工具详情按 `tool_use_id` 配对请求与结果，原始日志和复制功能保留完整内容。

工作流可视化读取后端 Observation API，或离线加载 `derived/observer_trace.json`。
原始 Transcript 页面读取原始 JSONL 快照；调用链卡片只做展示整理，不改写原始记录。

macOS 的 `start_agentvast_web.sh` 使用 `claude_ccs.sh` 启动 Claude。该脚本直接调用本机
Claude，读取 CC Switch 写入的 Claude 全局配置，不从项目 `.env` 注入 API 或固定模型。
手动切换配置后，下次启动或恢复会话生效；项目 `.env` 继续供工作流语义处理使用。
终端启动行列数来自浏览器实际尺寸，隐藏页面不会向进程发送缩小尺寸。
同一会话的多个浏览器页面各自记录尺寸；点击或输入终端的页面控制进程尺寸，其他预览页面
不会覆盖它。控制页面断开或隐藏后释放控制权。

生成 `derived/semantic_workflow.json` 后，工作流可视化页面显示证据约束的语义工作流。

工作流画布可拖动平移、滚轮或触控缩放；左下角提供缩放比例与加减按钮，右上角可定位当前
阶段或查看全图。点击图中阶段只更新详情，保留当前视角；阶段目录提供明确的跳转定位。
目录、阶段详情和分析设置均可收起，窄窗口使用浮层以保留画布空间。模型、并发度和阶段耗时
在分析设置中查看；摘要要求、重新生成与检查点恢复入口保留在同一面板。
详细执行图在 Event 右下角用四类图标及编号展示文件交互，如“代码1”“数据集3”；产物目录支持
分类筛选。点击角标或文件条目可通过系统默认应用打开当前本地文件，缺失文件保留关联但禁用打开。
人工接受、字段修正、连续 Node 合并和按 Episode 拆分会写入
追加式 review sidecar，不会覆盖模型或规则生成的原始语义文件。

模型模式使用相邻 Candidate 的 `MERGE/SPLIT` JSON 决策；前端分别显示 Evidence Validity、
Granularity Validity、模型置信度、校验后置信度，以及模型边界被硬约束覆盖的原因。

Semantic Annotation 采用逐 Episode 模型调用。点击模型生成后，页面轮询后端进度，显示候选块、
边界判断、当前 Episode、关系提取和最终验证等阶段，不再让一个长同步请求无反馈地等待。

## 设计原则

参考 `agentvast/visualization/vis-guide.md`：
- 不重新实现 DAG 绘制
- 专注将执行过程转换为具有语义的可解释 Provenance Graph
- 使用现成的布局库（Dagre/ELK）

动态执行图：新建或恢复 Claude 会话后，可在终端页点击「查看动态执行图」。事实和原始日志自动刷新；点击「语义分析」选择 Turn 后才开始解析。逐轮状态、版本和失败重试见 [动态 Turn Trace](../docs/DynamicTurnTraceV1.md)。

终端恢复：连接前先测量真实网格，历史回放期间屏蔽历史设备查询回传，过期 WebSocket 不再写入当前屏幕；切换终端会话时释放旧 xterm 实例。发生显示错位可点击「重绘终端」（Ctrl+L），保留当前输入和会话历史。PTY 输入在系统只写入部分字节时继续写完，避免长中文输入截断。
